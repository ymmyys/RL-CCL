## 1. 模型与记号(§3.1)

**实体与参数.** 源主机集 `H = {1,…,m}`(训练侧):主机 `h` 持有 shard `W_h ≥ 0` 字节,`Σ_h W_h = W`(Megatron 切分给定);NIC 聚合 egress 容量 `u_h`(约定 `W_h > 0 ⟹ u_h > 0`,否则平凡不可行);`u_S := Σ_h u_h`。目标主机集 `D = {1,…,N}`(推理侧):每个 `j ∈ D` 需要完整 `W` 字节;NIC 聚合 ingress 容量 `d_j > 0`;可用于 relay 的 egress 预算 `r_j := ρ_j·u_j`,其中 `ρ_j ∈ [0,1]` 是 KV cache / decode 流量对推理主机上行的节流系数;`R := Σ_j r_j`。

**假设.**

- **A1(主机粒度流体模型).** 字节无限可分;一个调度 `σ` 是可测速率函数族 `{z_{a→b}(t)}` 加逐字节归属;主机 `v` 在 `t` 时刻的持有集 `F_v(t) ⊆ [0,W)` 单调不减。机内 GPU 扇出免费(NVLink/PCIe ≫ NIC),故**节点 = 主机**。
- **A2(单 owner 切分).** 每字节初始 holder 唯一,`F_h(0)` 两两不交、`|F_h(0)| = W_h`。(DP 复制导致的多 holder:引理 1 给出一般形式;主定理前需 owner 指派预处理,见 §7。)
- **A3(全双工).** 收、发互不挤占。约束:源 `h` 总发送 ≤ `u_h`;目标 `j` 总发送 ≤ `r_j`、总接收 ≤ `d_j`;源 `h` 总接收 ≤ `u_h`(对称 NIC,仅源→源 relay 时相关)。
- **A4(非阻塞全连通 fabric).** 任意主机对可并发以任意速率通信,仅受 A3 的 NIC 聚合约束(RDMA fat-tree / rail-optimized 的理想化)。
- **A5(存储转发因果性 + 流体直通).** `t` 时刻 `a` 只能发送 `F_a(t)` 中的内容;允许速率匹配的流式直通(边收边转,转发速率 ≤ 接收速率),与 KR/MWW 的 fluid 用法一致;离散 chunk 滞后见 §5 末 Remark。
- **A6(静态容量).** 传输窗口内 `u, d, ρ` 不变;churn 交给执行层。

**目标.** makespan `T(σ) := inf{ t : ∀ j∈D, F_j(t) ⊇ [0,W) }`;`T* := inf_σ T(σ)`。

**调度类 Σ₂(无源侧 relay).** 源主机永不接收(每字节路径形如 owner → 目标 relay 链)。本文构造只用其中的**两跳子类**(每字节到任一目标至多经 1 个中转)。

**与经典模型的精确关系.**
1. 取 `m = 1`、`ρ_j ≡ 1`,本模型逐字还原 **Kumar–Ross HOTWEB'06** 的单种子 fluid 模型(`u(I) = u_S + Σ_j u_j`),其 Thm 1 是本主定理的特例。
2. **MWW J.Scheduling'08** Thm 4 的多源模型中每个参与者既是源也是汇,无纯 sink、无 ingress 参数、无 ρ 节流;本模型的目标初始为空且有 `d_j`、`ρ_j`。

两模型均**不**包含本模型:本模型 = sharded 源(MWW 型)+ 纯接收 leecher 且带 ingress 约束(KR 型)+ relay 节流 ρ(两者皆无)之并,文献无现成闭式。

## 2. 引理 1(割界族)与命题 1

### 引理 1(割界族,多 holder 一般形式)

设每字节 `b ∈ [0,W)` 的初始 holder 集 `H(b) ⊆ H` 非空(A2 下 `|H(b)| = 1`)。对任意 `A ⊆ H ∪ D`,定义割负载

```
X(A) := Leb{ b : H(b) ⊆ A }   若 D ⊄ A;  否则 X(A) := 0,
```

割容量 `c(A) := min{ out(A), in(Aᶜ) }`,其中

```
out(A) = Σ_{h∈A∩H} u_h + Σ_{j∈A∩D} r_j,
in(Aᶜ) = Σ_{h∈H∖A} u_h + Σ_{j∈D∖A} d_j。
```

则任意可行调度满足 **`T ≥ X(A)/c(A)`**。

**证明.** 设 `D ⊄ A`(否则平凡)。令 `B := {b : H(b) ⊆ A}`,取定 `j* ∈ D∖A`。定义 `Y(t) := Leb{ b∈B : ∃ v∉A, b∈F_v(t) }`。`t=0` 时 `B` 中每字节的全部副本在 `A` 内,故 `Y(0)=0`;`t=T` 时 `j*∉A` 持有全部 `[0,W)`,故 `Y(T) = |B| = X(A)`。`Y` 只能经跨割传输增长:若 `b∈B` 在 `t⁻` 时刻在 `A` 外无副本,则此刻任何把 `b` 送出 `A` 的传输,其发送方必持有 `b`(A5 因果性,流体直通不让字节瞬移跨割),而 `b` 的所有副本都在 `A` 内,故发送方 `∈A`、接收方 `∉A`。由 A3,任意时刻 `A→Aᶜ` 的总速率既 `≤ out(A)`(注意 `A` 内目标的发送容量是节流后的 `r_j` 而非 `u_j`),又 `≤ in(Aᶜ)`。积分:`X(A) ≤ T·c(A)`。∎

**推论(典范割).**
- **(C1) 源子集割.** `A = S ⊆ H`,得 `T ≥ W(S)/u(S)`,`W(S) := Leb{b : H(b) ⊆ S}`。A2 下 `W(S) = Σ_{h∈S} W_h`,由 mediant 不等式 `(Σa_h)/(Σc_h) ≤ max_h a_h/c_h` 得
  ```
  max_{S⊆H} W(S)/u(S) = max_h W_h/u_h =: LB1
  ```
  (逐 owner 割在源侧割中最紧)。多 holder 时不坍缩,源侧割族保持为 `max_{S⊆H} W(S)/u(S)`。
- **(C2) 单目标 ingress 割.** `A = (H∪D)∖{j}`,`X(A) = W`,`c(A) ≤ d_j`,得 `T ≥ W/d_j`;取 max 得
  ```
  LB2 := max_j W/d_j = W/min_j d_j。
  ```

### 命题 1(混合割被支配)

A2 下,对任意 `A` 有 `X(A)/c(A) ≤ max{LB1, LB2}`;即整个割界族的上确界恰为 `max{LB1, LB2}`,**公式第三项(功守恒)不属于割界族**。

**证明.** `X(A)/c(A) = max{ X(A)/out(A), X(A)/in(Aᶜ) }`,两支分别支配:
- **(egress 支)** 目标初始为空 `⟹ H(b)⊆A ⟺ H(b)⊆A∩H =: S`,故 `X(A) = W(S)`;而 `out(A) = u(S) + r(A∩D) ≥ u(S)`,故 `X(A)/out(A) ≤ W(S)/u(S) ≤ LB1`(mediant)。即混合割把目标放进 `A` 只会往分母添 `r_j` 而不增大分子,egress 支上严格不优于纯源割。
- **(ingress 支)** `X(A) ≤ W`;因 `X(A) > 0` 蕴含 `D∖A` 非空,任取 `j₀∈D∖A`,`in(Aᶜ) ≥ d_{j₀}`,故 `X(A)/in(Aᶜ) ≤ W/d_{j₀} ≤ LB2`。∎

**注.** 命题 1 解释了为何 `LB_cut = max{LB1,LB2}` 单独可以任意松(repo 数值反例 `2.86×` ~ `N×`):当 relay 池是瓶颈时,任何单一割都数不出「每字节要投 N 份」这件事;第三项必须由引理 2 的计数论证(等价地,N 个 ingress 割的 LP 对偶组合)给出。

## 3. 引理 2(功守恒界,含 ρ 节流)

任意可行调度满足 **`T ≥ N·W/(u_S + R)`**,`R = Σ_j ρ_j u_j`。

**证明.** 令 `Φ(t) := Σ_{j∈D} |F_j(t)|`(目标侧已持有字节总量;同一字节重复到达不增加 `Φ`)。`Φ(0)=0`(目标初始为空,旧权重不计),`Φ(T) = N·W`。`Φ` 的瞬时增长率 ≤ 全体「接收方∈D」的传输速率之和;按发送方分解:发送方 `∈H` 的部分 `≤ Σ_h u_h = u_S`,发送方 `∈D` 的部分 `≤ Σ_j r_j = R`(A3,目标发送侧已被 ρ 节流)。故 `Φ'(t) ≤ u_S + R` a.e.,积分得 `N·W ≤ T·(u_S+R)`。∎

**注记(证明中已隐含、后文要用的四件事).**

- **(a) 计数性质.** 分子 `N·W` 把每字节按需求方计 N 次,故它不是任何单割(命题 1:割界族 `≤ max{LB1,LB2}`);它可视为 N 个单目标 ingress 割的对偶组合,数值上可严格强于一切割界。
- **(b) 源→源 relay 不破坏该界.** 接收方 `∈H` 的传输(`h₁→h₂` staging)消耗源 egress 却不推进 `Φ`,只会让上界 `Φ' ≤ u_S+R` 更难取满——界对含 staging 的任意调度无条件成立。定量版:若调度的入源传输总量为 `V_s`,则总传输量 `≥ N·W + V_s` 而总 egress 预算 `≤ T(u_S+R)`,故 **`T ≥ (N·W + V_s)/(u_S+R)`**。
- **(c) 引理 2.1(零浪费刻画).** 若某调度达到 `T = N·W/(u_S+R)`,则它 a.e. 满足 (i) 无源→源、无目标→源传输;(ii) 无重复投递;(iii) 全部源 egress 与目标 relay egress 在 `[0,T]` 满载。证明:任一违反使 `Φ(T) < T(u_S+R) = N·W`,矛盾。(主定理 (v) 的必要性方向用。)
- **(d) 分母含义.** `u_S+R` 是「可指向目标侧的池化 egress」。`h₂` 代发 `h₁` 的字节时占用的仍是这同一池子(`h₂` 的 `u_{h₂}`),分子 `N·W` 不变——「谁的字节经谁发」在此界层面无需区分,staging 的代价已由 (b) 单独记账。

## 4. 定理 1(主定理:统一闭式及其成立条件)

记 `LB1 = max_h W_h/u_h`,`LB2 = max_j W/d_j`,`LB3 = N·W/(u_S+R)`,

```
T_max := max{LB1, LB2, LB3}。
```

**平衡条件 (★):**

```
Σ_h min(N·W_h, T_max·u_h) + T_max·R ≥ N·W。
```

> **直觉.** owner `h` 在 `T_max` 内亲自投递不超过 `min(N·W_h, T_max·u_h)` 份——受自身 egress 与「每字节至多 N 个收方」双重封顶;relay 池至多投递 `T_max·R` 份;(★) 说不借源→源 staging 也凑得齐全部 `N·W` 份投递,即没有 owner 的 egress 被「搁浅」到不可用的程度。**O(m) 可检验。**

**定理 1.** 在 A1–A6 下:

1. **(i)** 无条件地 `T* ≥ T_max`(引理 1 的 C1/C2 + 引理 2)。
2. **(ii)** **若 (★) 成立,则 `T* = T_max`**,由显式两跳条带调度达到(§5);该调度属于 Σ₂(无源→源 relay)、每字节至多一跳中转、所有目标恰在 `T_max` 同时完成。
3. **(iii)** 一般情形(不设 (★)):在 Σ₂ 内 **`T*_{Σ₂} = max{LB1, LB2, T_wf}`**,其中
   ```
   T_wf := min{ T ≥ 0 : Σ_h min(N·W_h, T·u_h) + T·R ≥ N·W }
   ```
   是单调不减分段线性函数的最小根(`O(m log m)` 可算)。恒有 `T_wf ≥ LB3`;两跳在 Σ₂ 内已最优。且 `(★) ⟺ T_wf ≤ T_max ⟺ T*_{Σ₂} = T_max`。
4. **(iv)** (★) 的充分条件:
   - **(a)** `m = 1` 时 (★) 恒成立——即单 owner 情形定理无条件给出 `T* = max{W/u₁, W/min_j d_j, N·W/(u₁+R)}`,这是 KR Thm 1 加 ρ 节流的**严格推广**(`ρ≡1` 时逐字还原 KR)。
   - **(b)** 平衡律 `N·min_h W_h/u_h ≥ T_max`。
   - **(c)** 比例切分(`W_h/u_h ≡ W/u_S`)且 `u_S ≤ N·min_j d_j`。
5. **(v)** (★) 的必要性边界:**若 `LB3 > max{LB1,LB2}`,则 `T* = T_max ⟹ (★)`**(即此 regime 下 (★) 充要)。若 `T_max = LB1` 或 `LB2` 严格最大,(★) 非必要:源→源 staging 可能在 (★) 失败时仍达到 `T_max`(§7 给出实例)。

**证明.** (i) 即两引理。(ii)(iii) 可达性 = §5 构造。

(iii) 必要性:取 `σ∈Σ₂`、makespan `T`。Σ₂ 中源 `h` 永远只持有自己的 `W_h`。计数 `(字节, 目标)` 投递对,共 `N·W` 对,每对至少被服务一次:由 `h` 首次服务的对数 `≤ min(h 的总发送量, N·W_h) ≤ min(T·u_h, N·W_h)`;由目标服务的对数 `≤ T·R`。故 `Σ_h min(T·u_h, N·W_h) + T·R ≥ N·W`,由单调性 `T ≥ T_wf`;割界给出 `T ≥ LB1, LB2`。

(iv)(a):`m=1` 时 (★) 为 `min(N·W, T_max·u₁) + T_max·R ≥ N·W`;若 `T_max·u₁ ≥ N·W` 显然,否则化为 `T_max·(u₁+R) ≥ N·W ⟺ T_max ≥ LB3`,真。故 (★) 只可能因**多 owner 间不平衡**失败。(b):条件 `⟹ ∀h` 取 `min = T_max·u_h ⟹` 左边 `= T_max(u_S+R) ≥ N·W`。(c)⟹(b):比例切分下 `N·W_h/u_h ≡ N·W/u_S`,而 `T_max` 三项均 `≤ N·W/u_S`。

(v):设 `LB3 > max{LB1,LB2}` 且 (★) 失败,记缺口 `Δ := N·W − Σ_h min(N·W_h, T_max·u_h) − T_max·R > 0`,证 `T* > T_max`。任取调度 `σ`,入源 staging 总量 `V_s`。计数不等式推广为(用 `min(a, b+c) ≤ min(a,b)+c`):`N·W ≤ Σ_h min(T·u_h, N·W_h) + N·V_s + T·R`。若 `T ≤ T_max + δ`(δ 小使左式缺口 `≥ Δ/2`),则 `V_s ≥ Δ/(2N)`;再由引理 2 注 (b):`T ≥ (N·W + V_s)/(u_S+R) ≥ LB3 + Δ/(2N(u_S+R)) > T_max`。矛盾,故 `T* ≥ T_max + min{δ, Δ/(2N(u_S+R))} > T_max`。∎

> **论文声明格式(收窄版,可辩护):**
> *"Theorem: Under A1–A6 and the balance condition (★), `T* = max{LB1, LB2, LB3}`."*
> (★) 是一行可检验不等式;planner 先验证 (★),不满足则回退 (iii) 的 waterfill 闭式(Σ₂ 内仍精确)或含 staging 的完整 LP(§7)。

## 5. 可达性:两跳条带化构造

给定 `T` 满足 `T ≥ max{LB1, LB2}` 且 `Σ_h min(N·W_h, T·u_h) + T·R ≥ N·W`(定理 (ii) 中 `T=T_max` 由 (★) 保证;(iii) 中 `T = max{LB1,LB2,T_wf}`)。设 `N ≥ 2`(`N=1` 见 §6)。

- **Step 1(owner 直发份数).** 对 `W_h > 0` 令 `x_h := min{N, T·u_h/W_h}`;由 `T ≥ LB1` 得 `x_h ≥ 1`。令 `φ_h := (x_h−1)/(N−1) ∈ [0,1]`,把 `h` 的 shard 切成:全直发块 `D_h`(体积 `φ_h·W_h`,owner 直发给全部 N 个目标)与枢轴块(体积 `(1−φ_h)·W_h`,owner 只发一份给枢轴,由枢轴转发其余 `N−1` 份)。`h` 的每字节平均出手份数恰为 `N·φ_h + (1−φ_h) = x_h`。
- **Step 2(relay 配额,ρ 加权 waterfill).** 总 relay 投递需求 `Λ := Σ_h (N−x_h)·W_h = N·W − Σ_h min(N·W_h, T·u_h) ∈ [0, T·R]`。若 `Λ > 0`(必有 `R > 0`),令 `β_j := r_j/R`,把每个枢轴块按 `β` 再切成 `P_{h,j}`(体积 `(1−φ_h)·β_j·W_h`)。**`ρ_j=0` 的目标 `β_j=0`:永不做枢轴、纯接收**——这就是对 ρ 异构(KR Case C 要求全员上传)的适配。
- **Step 3(显式恒定速率,`[0,T]` 上常速,A5 直通).**
  - `h →` 每个 `k∈D`:流 `D_h`,速率 `φ_h·W_h/T`;
  - `h →` 枢轴 `j`:流 `P_{h,j}`,速率 `(1−φ_h)·β_j·W_h/T`;
  - 枢轴 `j →` 每个 `k≠j`:流 `∪_h P_{h,j}`,速率 `β_j·V/T`,其中 `V := Σ_h(1−φ_h)W_h = Λ/(N−1)`。

**约束逐条验证(三类容量).**
1. **源 egress:** `h` 的总发送速率 `= [N·φ_h + (1−φ_h)]·W_h/T = x_h·W_h/T ≤ u_h`。
2. **目标 relay egress:** 枢轴 `j` 的发送速率 `= (N−1)·β_j·V/T = β_j·Λ/T = (r_j/R)·(Λ/T) ≤ r_j`。
3. **目标 ingress:** `j` 的接收速率 `= Σ_h φ_h W_h/T`(直发)`+ β_j·V/T`(自己当枢轴)`+ Σ_{j'≠j} β_{j'}·V/T`(来自其他枢轴)`= (Σ_h φ_h W_h + V)/T = W/T ≤ d_j`。每目标每字节恰收一次、以恒速进账、**在 `T` 同时完成**。
4. **因果性:** `P_{h,j}` 由枢轴边收边以相同速率转发(A5 直通);无源→源、无目标→源 `⟹` 构造 `∈ Σ₂` 且两跳。
5. **记账自洽:** 总投递 `= Σ_h x_h W_h + Λ = N·W`,无重复。

**瓶颈情形对照(仿 KR 四 case;统一构造自动覆盖).**
- **Case A/B(Ingress,`T = LB2` 最大):** (3) 取等,目标 ingress 满载。对应 KR 的 `d_min` 瓶颈。
- **Case C(Work,`T = LB3` 最大且 (★) 成立):** 若无 owner 封顶(`∀h: T·u_h ≤ N·W_h`),则 `Σ min = T·u_S`,`Λ = T·R`——(1)(2) **同时取等**:全部源与全部 relay egress 满载,实现引理 2.1 的零浪费;relay 负载按 `β_j ∝ ρ_j u_j` 分摊,替代 KR 的均匀 `s_i`。
- **Case D(Source,`T = LB1` 最大):** 瓶颈 owner `h*` 有 `x_{h*} = T·u_{h*}/W_{h*}`;当其 `= 1` 时 `h*` 每字节只出手一次、egress 恰为 `W_{h*}`(KR「源每字节只发一次」)。
- **Owner 间不平衡的处置:** 若 (★) 成立,即便 `W_h/u_h` 各异也无需源→源 relay——快 owner 以 `x_h>1` 多直发、慢 owner `x_h→1` 把扇出全推给 relay 池。若 (★) 失败,Σ₂ 内的精确最优是 `T_wf`(定理 (iii)),而源→源 staging 可严格改进(§7)。

**退化子情形.** `R=0 ⟹` 强制 `x_h≡N`、`Λ=0`,构造退化为全直发,无 β 除零;`N=1` 时 `x_h≡1`、无枢轴块。

**Remark(离散化).** 每条流按 `M` 个等长 chunk 流水:路径深度 `≤2`,唯一转发跳滞后一个 chunk 时间 `= T/M`,故离散 makespan `≤ T·(1+1/M)`;对照 MWW Thm 1 的 `1+⌈log₂N⌉/M`(其内部扩散深度 `O(log N)`,我们恒为 1)。工程上 chunk 取若干 MB 即可忽略,引用为近似声明。

## 6. 边界情形

1. **`N=1`.** `LB3 ≤ W/u_S ≤ LB1`(mediant),max 公式仍正确、第三项松;(★) 恒成立;构造退化为各 owner 直发。`T* = max{LB1, W/d₁}`。
2. **`ρ≡0`(全禁 relay,`R=0`).** waterfill 根闭式化:`T_wf = N·max_h W_h/u_h`,故 `T*_{Σ₂} = max{LB2, N·max_h W_h/u_h}`(每 owner 自己把 shard 广播 N 遍);比例切分时三项公式精确。非比例且不满足时属源→源 staging 缺口 regime(§7 例 1 正是 `R=0`)。
3. **单 owner(`m=1`).** (★) 无条件成立(定理 (iv)(a)),`ρ≡1` 时逐字还原 KR Thm 1——一致性校验通过。结论:**(★) 失败只能源于多 owner 不平衡**。
4. **`d=∞`.** `LB2` 消失,(★) 下 `T* = max{LB1, LB3}`,MWW 风味的「容量池」答案。
5. **源目标容量悬殊.** `u_S` 极大 `⟹` owner 全直发(KR Case A/B 型);`R` 极大(`ρ→1`)`⟹ T* → max{LB1, LB2}`,relay 池吸收 `(N−1)W`(KR Case D 型);`d_min` 极小 `⟹ T = LB2`。
6. **退化参数.** `W_h=0` 的旁观源:(★) 中 `min(0,·)=0` 自动排除其贡献;失败时它正是最典型的「搁浅 egress」(§7 例 1)。`ρ_j=0` 的目标:`β_j=0` 纯接收。`u_h=0` 且 `W_h>0`:`LB1=∞`,与 `T*=∞` 一致。

## 7. 遗留缺口(诚实标注)

1. **(★) 失败 regime(源→源 staging 必要)无闭式.** 典型例:`m=2`,`W₁=W`、`W₂=0`,`ρ≡0`,`u₂ ≫ u₁`:Σ₂ 内精确最优 `T_wf = N·W/u₁`,而 staging 调度(`h₁→h₂` 流水 + `h₂` 代播)达到 `≈ W/u₁ = LB1 = T_max`,**Σ₂ 相差 N 倍**。该例同时证明:(a) (★) 仅充分不必要;(b) 定理 (v) 的充要刻画只在 `LB3` 严格最大时成立,`LB1/LB2` 最大时的充要边界**开放**。含 staging 的一般最优是一个小 LP(planner 的 MILP oracle 已覆盖),其闭式与「两跳 + 至多一次源侧 staging 是否总最优」(3-hop 上界猜想)留作后续。
2. **多 holder(DP 复制).** 引理 1 已给一般割 `max_{S⊆H} W(S)/u(S)`;owner 指派在流体下并入 LP 为分数指派(多项式),但「最优指派后 (★) 是否总可满足」未刻画。主定理按 A2 单 owner 声明。
3. **fabric 理想化(A4).** 忽略 oversubscription 与 rail 亲和。rail 粒度是直接推广:割界逐 rail 化、构造按 `(owner, pivot, rail)` 分条,未在本文展开。
4. **系统常数.** 离散化 `(1+1/M)` 已证;QP/流数上限、建连开销、`ρ_j(t)` 随 decode 负载时变(A6)未建模,由 executor 自适应。
5. **多需求类共享 relay 预算.** 主定理是单需求类(整个 `W`)。代码 `_plan_stripe` 用 fleet-wide 水位跨类分摊 relay 预算,多类共享预算的闭式理论未覆盖,可能跨类超订某 pivot——理论-代码有缺口(见 §8 P1)。
6. **跨迭代流水与在线鲁棒版本.** 上一轮广播与下一轮训练重叠、`ρ_j(t)` 对抗变化下的 regret,未建模。

### 8.3 P1 / P2

### 8.4 可发表性判断
